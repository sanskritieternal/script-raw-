# Niche master list

**530 niches** across **46 subject categories**. This list is generated from [NICHE_TAXONOMY.csv](NICHE_TAXONOMY.csv) and each niche's `ANGLE_PLAN.json`.
The ID is the stable project identity. The subject is its current Q1 category; each niche has its own CAT configuration and output folder.

Browse by [subject category](CATEGORY_INDEX.md) or see the [niche directory](Niches/README.md). `Draft` plans need editorial review before an episode is researched.

Refresh this file after taxonomy or plan changes with `python build_niche_master_list.py`.

Each angle has a focus, coverage, evidence directions and limits. See the [angle scope guide](ANGLE_SCOPE_GUIDE.md) for editing and production use.
