# Selected primary-source note: embroidery

Checked 2026-10-24. Proposed cases BANK-266-042 and BANK-266-043.

The Metropolitan Museum of Art object 2024.241 records a circa-1850 wool-and-silk-on-linen sampler from the Roman Catholic Orphan Asylum in New York. The maker is listed as unknown; the museum explains that the work is signed by institutional status rather than the girl's name: https://www.metmuseum.org/art/collection/search/910938 . This is a bounded object and catalog attribution, not a full biography, proof of later employment, or evidence that all girls had the same experience. The record labels its image Public Domain; confirm asset metadata before reuse.

UNESCO's 2021 inscription page for the art of embroidery in Palestine links the State of Palestine nomination, community consent, and inventory documents. Its element description says thob decoration can indicate regional and social context, and describes women teaching within families, groups and courses, including diaspora practice: https://ich.unesco.org/en/RL/art-of-embroidery-in-palestine-practices-skills-knowledge-and-rituals-01722 . This documents a 2021 heritage representation. It does not make every motif a universal fixed code or prove all communities consented to every later use. Date and attribute statements; seek bearer voices for a script and check film/photo rights.

Neighbor review: BANK-264-033/039 concern textile material/origin attribution; 265 covers woven structures and workshop labor; BANK-095-017 already covers Kutch embroidery. These proposals concern one embroidered object and one living heritage nomination.
