# Selected source and boundary note — 414 Amateur Science

Reviewed 2026-10-24. Proposed **BANK-414-043** concerns a documented GLOBE Clouds data-processing correction.

## Primary project records

- GLOBE Observer, [Clouds Data](https://www.globe.gov/en/web/globe-observer/get-data/clouds-data), publishes matched ground/satellite data and version notes. Version 2.0 corrected a matching-code window set at **0.15 hour (9 minutes)** instead of the intended **0.25 hour (15 minutes)**. The program says a regular volunteer identified the error; reprocessing from 2017-01-01 added over 54,000 matches, reported as 36% more. These figures describe that release and processing step, not all current files.
- GLOBE, [Clouds observation protocol](https://www.globe.gov/web/s-cool/home/observation-and-reporting), describes the plus-or-minus-15-minute satellite comparison window. The [current data page](https://www.globe.gov/en/web/globe-observer/get-data/clouds-data) lists later versions and ongoing yearly releases, so preserve file name and version when comparing counts.

## Limits and overlap

The correction changes which submitted observations receive satellite matches; it does not establish that volunteers' original cloud classifications were right or wrong, nor a causal environmental trend. Satellite and ground views differ, and collection remains subject to coverage and volunteer-selection bias. Downloads may change; archive exact version/CSV and documentation before analysis. Respect location and image-sharing terms for individual submissions. **BANK-414-035** covers generic volunteer-data sampling bias; this named case focuses on an auditable matching-code change. **BANK-413-034** treats occultation timing, not GLOBE cloud data. New topic stays proposed with empty verified_sources; no IDEA readiness is asserted.
