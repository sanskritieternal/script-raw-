Reviewed 2026-10-24 for BANK-462-043. Proposed question only; no approval or production readiness is implied.

## Primary records

- Johns Hopkins University Center for Systems Science and Engineering, archived COVID-19 data repository: https://github.com/CSSEGISandData/COVID-19 . Its owner says the dashboard data collection and reporting ceased March 10, 2023, lists upstream sources, identifies attribution and CC BY 4.0 terms, and keeps the repository read-only.
- JHU CSSE data-directory README: https://github.com/CSSEGISandData/COVID-19/blob/master/csse_covid_19_data/README.md . It documents reporting timestamps, archive organization, retrospective corrections and variable definitions, including why some recovered/active data ceased to be maintained.

## Claim, access and rights limits

The repository documents a workflow and its stated policies, not a time-use study of employees, a proof that every source figure was correct, or an estimate of any one profession's labor demand. COVID case reports changed with testing and reporting practices; a retrospective correction is not evidence of misconduct. The project is archived, so do not present it as live. Attribute the dataset as the repository requests and check source-specific licenses before reuse of source data or dashboard images. A script should inspect particular commits and dated files before narrating one correction.
