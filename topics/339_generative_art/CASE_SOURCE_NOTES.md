# Selected institutional and artist source note — generative art

Inspected 2026-10-24 for `BANK-339-038`.

- [MoMA, *Refik Anadol: Unsupervised*](https://www.moma.org/calendar/exhibitions/5535) (exhibition November 19, 2022–October 29, 2023): the museum describes a real-time generative installation interpreting publicly available collection data and credits Refik Anadol Studio and collaborators. The museum's work description identifies custom software, AI generative algorithm, LED display, sound and variable dimensions.
- [MoMA Magazine, interview with Refik Anadol](https://www.moma.org/magazine/articles/821) (December 20, 2022): the artist describes the project's creative and technical choices. This is a participant account, not an independent technical audit.

Both pages were accessible. Their descriptions establish an exhibited work, broad data source and credited process. They do not inventory every training item, prove a particular model's complete lineage, settle rights or authorship law, or independently verify all software behavior. Exhibition dates refer to MoMA's cataloged run and should not be used as a universal date for every iteration of the work.
