# Selected primary monitoring source note — climate science

Inspected 2026-10-24 for `BANK-361-040`. The NOAA live graph and data page can change after this inspection; no live concentration value is frozen here.

- [NOAA Global Monitoring Laboratory, Trends in Atmospheric Carbon Dioxide](https://gml.noaa.gov/ccgg/trends/index.html): describes Mauna Loa monthly means, Scripps measurements beginning in March 1958, NOAA's parallel measurements beginning in May 1974, and a seasonal-cycle correction estimated from adjacent years.
- [NOAA GML data and revision notes](https://www.gml.noaa.gov/ccgg/trends/data.html): provides monthly and annual series and notes that quality-control checks can revise values. [NOAA Mauna Loa monitoring page](https://gml.noaa.gov/obop/mlo/programs/esrl/co2/co2.html) shows the site-specific seasonal cycle and fitted long-term trend.

The pages were accessible. A single high-altitude site is not by itself the global mean. Seasonal removal is an analytical choice, not erasure of measurement variation. The rising concentration record alone does not quantify climate sensitivity, attribute every temperature change, or represent an emissions inventory; those require additional lines of evidence. Data and methods should be dated again for any script using current values.
