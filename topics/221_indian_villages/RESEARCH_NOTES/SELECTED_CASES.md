# Selected Indian-village source checks

All linked questions remain **proposed**. Use a named village and dated records before interpreting any generic archived format.

## BANK-221-041 — Hiware Bazar watershed case

A [government-hosted village-development case collection](https://unnatbharatabhiyan.gov.in/public/uploads/documents/1678962142Guidelines_and_Case_Studies_for_Integrated_Village_Development_Planning.pdf) describes Hiware Bazar's watershed and local-governance interventions. It also notes discrepancies between land-area figures from census/government records and other project reports. This is a program case narrative, not an independent counterfactual assessment proving village-wide self-sufficiency, income effects or unanimous participation. Compare period, denominator and community accounts before scripting outcomes.

## BANK-221-042 — tap connection versus usable supply

The [Jal Jeevan Mission 2024 functionality-assessment index](https://jaljeevanmission.gov.in/functionality-report-2024) provides national and state assessment reports. The [survey-method example in the 2020–21 national report](https://jaljeevanmission.gov.in/sites/default/files/2024-04/Functionality-Assessment-National-Report-2020.pdf) distinguishes a listed household tap connection from measured quantity, quality, regularity and pressure in a sample. The index establishes report availability, not a current failure rate; read the selected state report and sampling frame before quoting one. This proposed case owns service functionality; BANK-221-030 owns settlement pattern around water sources.

## BANK-221-043 — plan versus project

The [Ministry of Panchayati Raj GPDP guidance index](https://www.gpdp.nic.in/downloadNew.html) and [People's Plan Campaign format](https://www.gpdp.nic.in/resources/files/Rev_Booklet_on_People_Plan_Campaign_310802.pdf) distinguish prior work, gap analysis, activities, funding and monitoring. A plan entry does not prove approval, expenditure, completion or community consent. Select one named Panchayat's dated plan and implementation record before claiming a result. Existing BANK-221-037 covers service responsibility more generally.
