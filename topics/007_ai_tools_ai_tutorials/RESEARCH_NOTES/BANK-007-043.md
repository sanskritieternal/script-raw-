This is a documentation-only source note for a future versioned tutorial. No Ollama or LM Studio executable was available on the current machine's command path, so no local installation, model run, offline test, packet capture or privacy audit was performed. The preserved queue title's “100% private, free, and offline” promise is not established.

## Inspected current vendor documentation

- [Ollama's FAQ](https://docs.ollama.com/faq) says locally run models do not send prompts to Ollama, while cloud-hosted models process prompts remotely. It documents an option to disable cloud features (`disable_ollama_cloud` or `OLLAMA_NO_CLOUD=1`), a restart and log check, internet use for model pulls, and a default loopback bind address that can be changed to expose the server. These are vendor claims and configuration instructions, not an independent observation of a particular installation.
- [LM Studio's offline-operation guide](https://lmstudio.ai/docs/app/offline) says previously downloaded local models, local document chat and a local server can run without connectivity. It separately identifies network-dependent model search, model and runtime downloads, and update checks. Its current [app privacy policy](https://lmstudio.ai/app-privacy) also distinguishes local use from optional cloud processing. Version, feature choice and surrounding integrations matter.

## Proposed test before a script

Record exact application, model, runtime and OS versions; download and license requirements; account or cloud settings; bind address and reachable clients. Use a harmless synthetic prompt and document. Run once with connectivity, then with network blocked, and separately inspect process connections or host firewall logs during startup, model search, update check, inference and export. Check whether any plugin, connector or UI layer sends data beyond the model server. Keep test outputs and failures. A local inference claim must not be expanded to “100% private” for an entire workflow, and the cost claim must include hardware, power, storage and maintenance. The vendor pages can guide the test but cannot substitute for it.
