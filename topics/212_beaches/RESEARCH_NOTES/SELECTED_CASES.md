# Selected beach-case source checks

All linked topics remain **proposed**. The preserved trending hooks have not been accepted as verified episode premises.

## BANK-212-014 — rip current

[NOAA's rip-current guidance](https://www.noaa.gov/break-grip-of-rip) explains a narrow seaward flow and explicitly distinguishes being carried away from shore from being pulled under. This bounds the existing mechanism question. The archived fixed annual-death number and a universal escape rule require a dated dataset and local conditions before any script uses them.

## BANK-212-037 — Papakōlea green sand

The [USGS Hawaiʻi geologic account](https://pubs.usgs.gov/gip/117/gip117_ebook.pdf) identifies olivine eroded from Puʻu o Mahana and concentrated by wave action. A [mapped Mauna Loa unit](https://pubs.usgs.gov/sim/2932/c/sim2932c_pamphlet.pdf) gives the local volcanic context. Existing BANK-212-015 covers sand-color mechanisms generally; this case owns a named source-and-transport record. Neither source establishes a worldwide rarity ranking.

## BANK-212-038 — Miami Beach sand sourcing

The [US Army Corps Miami Beach nourishment project page](https://www.saj.usace.army.mil/Missions/Civil-Works/Shore-Protection/Dade-County/Miami-Beach-Renourishment-2022-2023/) says major Miami-Dade offshore sources had been exhausted by a prior contract and describes subsequent phases. A [Corps regulatory notice](https://www.saj.usace.army.mil/Missions/Regulatory/Public-Notices/Article/3624509/saj-1999-04294sp-vek/) identifies specific authorized inland mine sources for one later site. Those records establish named project sourcing, not that every Miami beach or all future phases use inland sand. Existing BANK-212-023 owns general nourishment mechanics.
