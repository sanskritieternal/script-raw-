# Selected product-research source note — developer AI

Inspected 2026-10-24 for `BANK-338-040`.

- [GitHub, *Research: quantifying GitHub Copilot's impact on developer productivity and happiness*](https://github.blog/news-insights/research/research-quantifying-github-copilots-impact-on-developer-productivity-and-happiness/) (published September 7, 2022; page updated May 21, 2024): GitHub reports random allocation of 95 professional developers to Copilot and control groups for one JavaScript HTTP-server implementation task, automatic correctness/completeness scoring, and faster average completion for the Copilot group.

This is vendor-run research about a specific tool version, task, participant pool and measurement. The reported speed estimate cannot establish productivity for entire teams, security, long-term maintenance, review cost, arbitrary languages or current products. The page is accessible and gives a summary, not full reproducibility materials within the article. Do not quote a single percentage as a universal productivity gain.
