# Selected source and boundary note — 426 Roads & Highways

Reviewed 2026-10-24. Proposed **BANK-426-045** follows the Rochester, New York, Inner Loop East expressway-to-street project.

## Primary public-agency records

- Federal Highway Administration, [Inner Loop East project profile](https://www.fhwa.dot.gov/ipd/project_profiles/ny_freeway_to_boulvard_rochester.aspx), describes the eastern section conversion from a below-grade expressway to at-grade Union Street, new walking/cycling connections and land opened for development. It dates removal/construction November 2014–December 2017. The profile is a project/funding account and contains forward-looking claims alongside reported outputs; its different acreage figures must be reconciled before quoting.
- City of Rochester, [Inner Loop North project background](https://www.cityofrochester.gov/departments/department-environmental-services-des/inner-loop-north-transformation-project), identifies **Inner Loop East** as completed in 2017 and distinguishes the separate, ongoing North planning effort. Use the East project boundary only in this case.

## Limits and overlap

The agencies' project descriptions establish scope and reported completion, not an isolated causal effect on citywide congestion, affordable housing, safety or neighborhood equity. FHWA's estimated and post-project redevelopment/economic figures have different dates and definitions; check original evaluations before scripting a numerical outcome.
