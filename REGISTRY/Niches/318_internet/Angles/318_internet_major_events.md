## Editorial scope

**Focus / example question:** What failed first and which users were affected?

**Coverage:** Use dated operator reports and independent measurements.

**Evidence to seek:** dated RFCs and standards discussions, operator postmortems, public routing and DNS measurements, network maps, and consented user and worker accounts

**Limits:** Name protocol, service, vantage point, and date. Distinguish network from application and do not infer a complete path from one measurement.
