## SER-008-001 — Reading a money illustration

Entry requirement: No prior episode required; explain specialist terms on first use.

Learning outcome: Identify assumptions, costs and risks in a bounded educational example.

Ordering reason: Start with transparent arithmetic, add costs, then inspect what the model excludes.

1. **IDEA-008-0001** — Same savings example, different compounding (ready_for_project). For a fictional deposit with no contributions, how does changing compounding frequency alter the result when the annual rate is held fixed?
2. **IDEA-008-0002** — Where a fee enters a savings illustration (ready_for_project). How does one explicitly modeled annual fee change a hypothetical balance compared with the same assumptions before fees?
3. **IDEA-008-0003** — A balance projection is not a promise (ready_for_project). Which risks described in the SEC mutual-fund guide are absent from a constant-rate savings illustration?
