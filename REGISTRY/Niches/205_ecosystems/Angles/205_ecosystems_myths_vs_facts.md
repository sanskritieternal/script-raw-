## Editorial scope

**Focus / example question:** When does a biodiversity metric reflect function or resilience?

**Coverage:** Define taxa, scale, baseline, functional roles, and disturbance.

**Evidence to seek:** dated ecosystem maps and land-use records, repeat field protocols, sensor calibration, long-term monitoring, reference sites, and consented local accounts

**Limits:** Name place, ecosystem boundary, measure, season, and time span. Distinguish one indicator from overall system health and correlation from a demonstrated causal pathway.
