## Editorial scope

**Focus / example question:** Does open code come with the security and support being claimed?

**Coverage:** Test one claim that open code is automatically secure or supported against a defined project's processes and evidence.

**Evidence to seek:** Trace the public claim to original evidence and retain its qualifications. Case records: actual versioned licenses, repositories, contribution rules, release records and public security notices. Starting framework: Open Source Initiative definition (https://opensource.org/osd). Select and verify the dated underlying case sources before scripting.

**Limits:** Name license and version; open code does not guarantee security or support. Niche boundary: Open-source licensing, governance and maintenance ecosystems; coding tutorials and software architecture are neighboring subjects.

Before Phase 1, narrow this guidance to a specific case, source or work, and the relevant place, population, version or period. Record that choice in the episode's story question and research summary.
