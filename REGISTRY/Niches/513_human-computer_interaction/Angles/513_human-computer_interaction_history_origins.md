## Editorial scope

**Focus / example question:** Which user task led to an interaction technique's development?

**Coverage:** Trace one interaction technique from its original user task through design and evaluation; distinguish prototype influence from widespread adoption.

**Evidence to seek:** Trace dated origin records and subsequent interpretations. Case records: task protocols, participant criteria, usability observations, accessibility evidence and design records. Starting framework: W3C accessibility evaluation resources (https://www.w3.org/WAI/test-evaluate/). Select and verify the dated underlying case sources before scripting.

**Limits:** Test with users; interface preference alone is not measured benefit. Niche boundary: Human interaction with interfaces and measured task performance; product shopping and software implementation have separate homes.
