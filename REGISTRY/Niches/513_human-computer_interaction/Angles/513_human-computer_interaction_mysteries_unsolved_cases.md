## Editorial scope

**Focus / example question:** Why did real-world use differ from a usability test's prediction?

**Coverage:** Investigate a mismatch between a usability test and real-world behavior; compare context, incentives, training and excluded user groups.

**Evidence to seek:** Compare competing explanations and specify missing discriminating evidence. Case records: task protocols, participant criteria, usability observations, accessibility evidence and design records. Starting framework: W3C accessibility evaluation resources (https://www.w3.org/WAI/test-evaluate/). Select and verify the dated underlying case sources before scripting.

**Limits:** Test with users; interface preference alone is not measured benefit. Niche boundary: Human interaction with interfaces and measured task performance; product shopping and software implementation have separate homes.

Before Phase 1, narrow this guidance to a specific case, source or work, and the relevant place, population, version or period. Record that choice in the episode's story question and research summary.
