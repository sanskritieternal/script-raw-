## Editorial scope

**Focus / example question:** Which evaluation tasks establish learning beyond recall or familiarity?

**Coverage:** Compare evaluation methods for one media-literacy skill using unfamiliar tasks, comparison groups and delayed tests; distinguish knowledge from demonstrated performance.

**Evidence to seek:** Compare original methods, assumptions, measures and uncertainty. Case records: original claims and records, dated redistribution traces, lesson designs and original learning evaluations. Starting framework: UNESCO media and information literacy curriculum (https://www.unesco.org/mil4teachers/en/introduction). Select and verify the dated underlying case sources before scripting.

**Limits:** Check original evidence and assess learning, not just confidence. Niche boundary: Claim checking, media interpretation and evaluated learning; media history, account security and general education have separate homes.
