## Editorial scope

**Focus / example question:** Does a popular claim about speed, safety, or simplicity hold for a defined task?

**Coverage:** Compare pinned versions, workloads, measurement methods, and exceptions.

**Evidence to seek:** versioned source code and design discussions, official specifications and release records, reproducible tests and benchmarks, public incident reports, and user and maintainer accounts

**Limits:** Name product, version, platform, and workload. Reproduce measurements under stated conditions, check current advisories, and omit exploitable security procedures and private user data.

Before Phase 1, narrow this guidance to a specific case, source or work, and the relevant place, population, version or period. Record that choice in the episode's story question and research summary.
