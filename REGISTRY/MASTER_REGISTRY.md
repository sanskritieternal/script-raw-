# V6 MASTER NICHE REGISTRY — 500 Niches

> Master editable source database for the V6 Universal Content Factory.
> Lists the 500 stable niche IDs and 15 planning angles per ID. The current subject category, path, slug and preset are resolved from `REGISTRY/NICHE_TAXONOMY.csv` and `REGISTRY/CONFIG_SCHEMA.json` version 5.0.
> Base structure: 500 major niches with 15 angles each = 7,500 choices. The current 500 angle plans expand this to 16,016 candidate directions. These are not researched stories.

## Related Files (load together)

- **Visual Style Database:** `REGISTRY/MASTER_VISUAL_STYLE.md` (palette, lighting, camera, motion per niche)
- **Niche CAT configurations:** `REGISTRY/Niches/<ID>_<Slug>/CAT_<ID>_<Slug>.md` (editable Q1–Q42 defaults)
- **NICHE identity records:** `REGISTRY/Niches/<ID>_<Slug>/NICHE_<ID>_<Slug>.md` (planning links, without Q answers)
- **Angle choices:** `REGISTRY/Niches/<ID>_<Slug>/Angles/<ID>_<Slug>_<Angle>.md` (Q3 only)
- **Taxonomy:** `REGISTRY/NICHE_TAXONOMY.csv` (canonical ID-to-path mapping)
- **Category index:** `REGISTRY/CATEGORY_INDEX.md` (46 current subject categories and counts)

## Visual Style Lookup

Each niche (by ID number 1-500) maps directly to the same-ID entry in `MASTER_VISUAL_STYLE.md`.
When generating content for niche ID N, load the visual style from row N of `MASTER_VISUAL_STYLE.md` and apply it to Q15 (Visual Style Primary). Q40 (Video Generation Method) is a separate category or project choice.

## Category-to-Preset Mapping

Read `REGISTRY/NICHE_TAXONOMY.csv` for the current primary subject category and canonical home of each ID, then load that home's CAT file. Subject category, story angle and production format are independent fields; no numeric ID range determines category.
