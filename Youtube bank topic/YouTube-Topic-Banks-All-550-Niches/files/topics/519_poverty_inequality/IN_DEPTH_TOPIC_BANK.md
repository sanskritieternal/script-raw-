**Research standard:** Use original observations or experiments, an appropriate scientific reference and the actual measurement method. Distinguish mechanisms, correlations, model assumptions, uncertainty and limits of generalization.

**Source types to locate:** original research reports and data; research-institution observation records; methods papers and current scientific reference works. These source types are not topic-specific sources already inspected.

### Mechanisms

**Research standard:** Use current official terms, filings or macroeconomic data; state jurisdiction, date, fees, taxes, risk, units and assumptions. Use transparent illustrative calculations rather than personal recommendations or return promises.

**Source types to locate:** regulator or official statistical publications; actual contracts, fee schedules and audited filings; original economic studies and disclosed calculation inputs. These source types are not topic-specific sources already inspected.

### Policy evaluation

**Research standard:** Use the current official legal text, policy, procedure or public dataset for a specific jurisdiction and date. Distinguish written rules, implementation and lived access; give no personal legal or financial conclusion.

**Source types to locate:** official laws, rules and administrative guidance; audits, judgments and public service records; consented accounts from affected people and qualified specialists. These source types are not topic-specific sources already inspected.
