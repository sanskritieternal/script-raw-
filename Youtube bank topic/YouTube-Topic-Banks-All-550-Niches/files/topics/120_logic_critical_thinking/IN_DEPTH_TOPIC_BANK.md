**Research standard:** Define the rival claims and their evidence standards. Compare sources on equal terms, separate empirical findings from values or interpretations and do not imply that all positions have equal evidential support.

**Source types to locate:** the original sources behind the compared claims; explicit definitions and measurement methods; independent critiques with traceable evidence. These source types are not topic-specific sources already inspected.

### Evidence reasoning

**Research standard:** Use original observations or experiments, an appropriate scientific reference and the actual measurement method. Distinguish mechanisms, correlations, model assumptions, uncertainty and limits of generalization.

**Source types to locate:** original research reports and data; research-institution observation records; methods papers and current scientific reference works. These source types are not topic-specific sources already inspected.
