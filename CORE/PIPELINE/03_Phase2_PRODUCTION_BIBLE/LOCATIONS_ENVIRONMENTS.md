# Location and environment dossiers

## Location profiles

Repeat a complete individual dossier for each actual setting. Specify stable ID/version, name, narrative purpose, source versus design boundary, period/world, current scene use and proposed/approved status. Give concrete layout anchors/zones, routes, entrances/exits, relative scale, landmark geometry and persistent character positions. A simple labelled plan or normalized design grid may clarify the layout; do not present artistic coordinates as surveyed historical facts.

### Individual set construction

Describe ground/surfaces, vegetation/architecture/furniture where actually relevant, material/texture, proposed palette/light directions and what background detail supports the focal action. Choose actual art values rather than saying maintain consistency. Define wide/medium/detail camera locations and how reverse shots preserve eye lines and set geography. Do not add locations or objects merely to increase length.

## Environment variants and continuity

Map actual scene regions/events to the active set state. Identify what may change and what must remain stable: weather, light, season, damage, entrances, character marks and landmarks. Crops/reverses are views, not automatically new settings. Explain one failure/correction such as mirrored anchors or a time-of-day reset.

## Reference assets and scenes

Give the actual source locators and design references. Specify needed clean plates, layout, matching reverse/detail and scale sheets; record planned versus actual files/version/approval. Link related character, camera, prop and scene records with real episode-relative links.

## Generation and acceptance

Write one complete location-specific neutral reference prompt, an exclusion brief and a representative scene-adaptation example for each setting. Specify clean plate versus scene participants, framing/material/light/landmarks and correct active state. Define concrete acceptance/rejection evidence. Prompt syntax/capabilities remain model-specific; no reference file or visual approval is invented.
