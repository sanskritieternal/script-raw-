# Object and costume dossiers

## Prop and costume profiles

Repeat a full individual dossier for every important object/outfit. Give ID/version, narrative function, source/design boundary, owner/wearer, scene use and status. Specify concrete silhouette, parts/layers, proposed material/colour/finish, scale against the actual character, cut/fit/attachment and relevant variants. Describe accessory/weapon/jewellery inclusion or justified absence, not a blank category. Creative precision must not be presented as verified historical measurement or material.

### Individual reference and prompt brief

For each object/outfit specify views, pose/scale/contact studies and linked character/location assets. Supply a complete individual reference prompt and exclusions, not an instruction to write them later. Give a representative use and a failure/correction. Keep neutral sheets distinct from scene-action prompts and planned references distinct from actual attachments.

## Ownership and state changes

Use a before/action/after table for each meaningful reveal, transfer, damage, repair or costume change. Include actual scene/event IDs, active owner/wearer and persistent offscreen state. If handedness/attachment is proposed staging, label it and reconcile adjacent contacts. Distinguish visually similar objects explicitly; no duplicate or reset introduced by a cut.

## Evidence and reference assets

Link actual Phase 1 source claims and related appearance/timeline/asset records. Track proposed variants and real files/version/review separately. Approval requires genuine evidence; no invented checksum, license, rendering or reviewer.

## Generation and review

Check identity, silhouette/scale/material, contact/cloth motion, object count, owner and current scene state. Include concrete rejection and repair examples for each relevant object/outfit. Model-specific controls remain pending until verified. Keep irrelevant fields honestly inapplicable rather than padding them.
