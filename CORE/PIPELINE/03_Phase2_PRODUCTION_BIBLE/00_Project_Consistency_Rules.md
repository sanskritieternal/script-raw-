# Project Consistency Rules

## Purpose

**Purpose:** Master rules document for the entire project.

**Contains:**
- Subject category, target audience, story angle, exact total duration
- Accuracy bar and source quality level
- Scene duration strategy (FIXED 8-SECOND or VARIABLE)
- Content safety level
- Locks: Q3 story angle, Q15 visual style, Q16 voiceover, Q42 scene duration. Q21 is graphics requirement; Q24 is source quality. Q40 video generation method is separate from visual style.
- Tone/mood lock (e.g., "engaging storytelling with authoritative data moments")
- Controversy handling rules
- Domain-specific rules (e.g., "for scandals, legal review required for named accusations")
- What MUST stay identical across all scenes
- **Protected Fields card** — SceneNumber, Duration, Location, Chapter, Characters, TimeOfDay/Period (must not change after Phase 2)
