# Asset and rights register

## Purpose and applicability

Use stable asset IDs mapped to valid scenes. Record planned versus created filenames, creator/provider, source, license/usage restrictions, checksum and review evidence. Planned assets are permitted for text drafting but do not prove clearance. Include captions, narrator, fonts, graphics and eventual media. Never mark a nonexistent file created or reviewed.
