## Reusable shot library

Assign SHOT_001-style IDs to episode-appropriate recipes: establishing, medium interaction, close-up reaction, detail, explanatory diagram and transition. For each specify narrative purpose, framing/lens intent, subjects, movement, composition, lighting, duration intent and exclusions. List recipe scene uses; a recipe does not replace each scene's actual visual direction. Adapt shot choices to cartoon, documentary or abstract explanation.

## Spatial and animation continuity

Define screen direction, eyelines, action axis, relative scale and character/location/prop variant references. Record motion style, gesture range, contact/physics expectations and transitions. Link actual start/end states across clips, especially when one editorial scene uses multiple generated clips.

## External generation profile

Record selected generator/model/version or explicitly Pending selection. Record verified capabilities, reference input method, actual clip duration constraints, supported controls and date/source of capability verification. Follow the shared AI_GENERATION_HANDOFF.md guide. Do not assume that eight seconds, three characters or a fixed prompt length is a universal provider limit.
