# Source Credibility Guide

## Project: Navratri — The Nine Nights of the Divine Feminine

---

## Source Hierarchy

### Tier 1 — Primary Sources (Highest Credibility)

| Tier Level | Source Type | Examples | Minimum Tier For |
|---|---|---|---|
| 1 | Sacred/Primary texts | Devī Māhātmya, Mārkaṇḍeya Purāṇa, Kālikā Purāṇa | All mythological narratives, mantras, names of forms |
| 1 | Archaeological evidence | ASI reports on Indus Valley figurines | Historical claims about ancient worship |
| 1 | Original language manuscripts | Sanskrit manuscripts of Puranas | Any text-based factual claim |

**Tier 1 Rule:** These are the highest authority for this project. No claim can contradict a Tier 1 source without acknowledging the contradiction.

### Tier 2 — Verified Academic Sources (High Credibility)

| Tier Level | Source Type | Examples | Minimum Tier For |
|---|---|---|---|
| 2 | Peer-reviewed academic books | Coburn, Kinsley, Pintchman | Historical dating, academic interpretations, scholarly consensus |
| 2 | University publications | Harvard, Oxford, Banaras Hindu University | Historical analysis, comparative religion studies |
| 2 | Government archaeological/Historical records | ASI, state archaeology departments | Historical dates, archaeological findings |

**Tier 2 Rule:** Academic sources must be peer-reviewed or from recognized academic institutions. No blogs, Wikipedia, or unverified internet sources.

### Tier 3 — General Sources (Supporting)

| Tier Level | Source Type | Examples | Minimum Tier For |
|---|---|---|---|
| 3 | Reputable news/media | Established newspapers, documentary producers | Modern celebration reports, community news |
| 3 | Official records | State government festival records, Guinness WR | Festival statistics, record claims |
| 3 | Community documentation | Temple records, community organizations | Regional practice descriptions |

**Tier 3 Rule:** Tier 3 sources can be used for contextual and descriptive content, but NOT for primary factual claims about mythology, history, or philosophy.

---

## Minimum Tier Per Claim Type

| Claim Type | Minimum Source Tier | Required Sources |
|---|---|---|
| Mythological narrative (Devi Mahatmya) | Tier 1 | Devī Māhātmya + 1 academic commentary |
| Names of Navadurga forms | Tier 1 | Devī Māhātmya + Kinsley |
| Mantras | Tier 1 | Original text (Devi Mahatmya, Kalika Purana) |
| Historical dates | Tier 1 or 2 | Primary records or academic consensus |
| Archaeological claims | Tier 1 | ASI or equivalent |
| Regional celebration descriptions | Tier 2 or 3 | Academic or reputable community sources |
| Philosophical interpretations | Tier 2 | Academic source (Pintchman, Kinsley) |
| Modern celebration data | Tier 3 | Community records, news reports |
| Population estimates | Tier 3 | Pew Research or equivalent |

---

## How to Handle Conflicting Sources

| Scenario | Action |
|---|---|
| Two Tier 1 sources contradict | State both versions, note the variation, prefer earlier/more widely accepted |
| Tier 1 vs Tier 2 contradiction | Tier 1 wins (scripture > academic interpretation) |
| Tier 2 sources contradict each other | State range of academic opinion, cite both |
| Tier 3 source contradicts Tier 1/2 | Ignore Tier 3 — primary/academic sources take precedence |
| No source available | Do NOT include the claim. Mark as [UNVERIFIED — NEED SOURCE] |

---

## Wikipedia Policy

- **Never** use Wikipedia as a primary source
- **Acceptable** for background research only
- **Do not** cite Wikipedia in any output file
- **If** a Wikipedia article points to a credible Tier 1 or 2 source, cite THAT source instead

---

## Source Review Checklist

- [ ] Every mythological claim has a Tier 1 source
- [ ] Every historical date has a Tier 1 or 2 source
- [ ] Every Sanskrit/mantra reference is from a Tier 1 text
- [ ] Academic interpretations cite Tier 2 sources
- [ ] Modern claims cite Tier 2 or 3 sources
- [ ] No Wikipedia citations in any output
- [ ] No unsourced internet content
- [ ] Conflicting sources are acknowledged, not hidden
