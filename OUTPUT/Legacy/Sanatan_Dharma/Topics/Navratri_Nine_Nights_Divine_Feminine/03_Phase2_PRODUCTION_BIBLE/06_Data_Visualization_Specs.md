# Data Visualization Specs

## Project: Navratri — The Nine Nights of the Divine Feminine

---

## Data Visualization Priority: Moderate

---

## Visualizations Required

### 1. Navadurga Forms Overview (Scenes 26-35)

| Element | Specification |
|---|---|
| Type | Sequential card reveal |
| Format | Each of the 9 forms shown as a card/panel |
| Layout | 3×3 grid (9 forms) with color-coded backgrounds |
| Animation | Each card fades in sequentially (one per scene) |
| Labels | Devanagari name + transliteration + one-line description |
| Color coding | Per form (see Visual Style Guide) |
| Audio | Narration corresponds to each card |

### 2. Navratri Calendar/Timeline (Scene 3-5)

| Element | Specification |
|---|---|
| Type | Animated timeline |
| Format | Vertical timeline showing 9 nights + 10th day |
| Labels | Pratipada → Navami → Vijayadashami (Devanagari) |
| Colors | Each night gets its form's color |
| Animation | Progressive reveal from top to bottom |

### 3. Shakti Concept Diagram (Scenes 86-90)

| Element | Specification |
|---|---|
| Type | Conceptual diagram |
| Format | Circle/mandala showing Devi as central Shakti |
| Labels | Devanagari labels for each energy aspect |
| Colors | Saffron/gold/gradient |
| Animation | Radiating from center outward (Shakti emanating) |

### 4. Regional Celebration Map (Scenes 61-65)

| Element | Specification |
|---|---|
| Type | Animated map of India |
| Format | Map with 4 highlighted regions (Bengal, Gujarat, South, North) |
| Labels | Region names in Devanagari |
| Animation | Camera pans to each region as narration describes it |
| Style | Warm color overlay on neutral map |

### 5. Kumari/Girl Child Image (Scene 75)

| Element | Specification |
|---|---|
| Type | Iconographic representation |
| Format | Stylized representation of Kumari |
| Labels | "कुमारी पूजा" (Kumari Puja) |
| Colors | Soft gold/pink |
| Animation | Gentle pulse/glow |

---

## Chart Types

| Visualization | Chart Type | Source Data |
|---|---|---|
| Navadurga forms | Card/Grid layout | Devi Mahatmya, Kinsley |
| Navratri timeline | Vertical timeline | Devi Mahatmya (9 nights) |
| Shakti concept | Mandala/circular diagram | Devi Bhagavata Purana, Pintchman |
| Regional map | Annotated map | Regional cultural records |

---

## Animation Style

| Animation | Description |
|---|---|
| Card reveal | Each Navadurga card fades in with a subtle glow |
| Timeline progression | Vertical line draws downward, each night node lights up |
| Mandala | Geometric patterns rotate slowly (meditative pace) |
| Map pan | Smooth pan across India map with region highlights |
| Text overlay | Devanagari text fades in with a subtle gold shimmer |

---

## Color Scheme for Data Viz

- Background: Dark navy/black (#1a0033) with sacred geometry pattern
- Text: Gold (#FFD700)
- Accents: Per-form colors (saffron, vermilion, etc.)
- Lines/borders: Saffron (#FF9933) or gold

---

## On-Screen Labels

| Type | Content | Language |
|---|---|---|
| Form names | शैलपुत्री, ब्रह्मचारिणी, etc. | Devanagari only |
| Mantras | Full Devanagari mantras | Devanagari + transliteration |
| Dates/Nights | प्रतिपदा, द्वितीया, etc. | Devanagari |
| Region names | बंगाल, गुजरात, दक्षिण भारत | Devanagari |
| Key concepts | शक्ति, विजयादशमी, etc. | Devanagari + explanation |

---

## Placement Rules

| Visualization | Scene Range | Duration | Placement |
|---|---|---|---|
| Navadurga grid | 26-35 | 9 scenes (one form per scene) | Center screen |
| Navratri timeline | 3-5 | 3 scenes | Left-center |
| Shakti mandala | 86-90 | 5 scenes | Center, large |
| Regional map | 61-65 | 5 scenes | Full screen |
| Kumari icon | 75 | 1 scene | Center, smaller |
