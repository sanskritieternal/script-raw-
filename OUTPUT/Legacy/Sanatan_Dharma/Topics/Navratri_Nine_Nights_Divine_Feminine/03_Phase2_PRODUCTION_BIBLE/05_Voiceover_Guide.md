# Voiceover Guide

## Project: Navratri — The Nine Nights of the Divine Feminine

---

## Voice Profile

| Attribute | Specification |
|---|---|
| Language | Hindi (Devanagari) |
| Gender | Female preferred (matching the Divine Feminine theme) — Male acceptable |
| Age | 30-45 years (mature, warm, authoritative yet devotional) |
| Accent | Neutral Hindi (understood across Hindi-speaking regions) |
| Tone | Devotional reverence + narrative storytelling |

## Pacing

| Content Type | WPM | Notes |
|---|---|---|

| Navadurga descriptions | 125 WPM | Measured — each form deserves individual attention |
| Festival descriptions | 140 WPM | Energetic — captures the excitement of celebration |
| Philosophical passages | 115 WPM | Slowest — needs contemplation |
| Closing/Jai Mata Di | 110 WPM | Most deliberate — spiritual gravity |
| Average overall | 125 WPM | — |

## Tone Rules

### Per Scene Type

| Scene Type | Tone | Volume | Energy |
|---|---|---|---|
| Opening (cosmic battle) | Epic, awe-inspiring | Full | Building |
| Devi Mahatmya passages | Devotional, sacred | Medium-full | Rising |
| Navadurga descriptions | Reverent, educational | Medium | Steady |
| Mantra recitations | Sacred, resonant | Full | Sacred |
| Regional celebrations | Joyful, celebratory | Medium-high | Varied |
| Philosophy passages | Contemplative, wise | Medium | Low-simmer |
| Modern celebrations | Warm, connecting | Medium | Varied |
| Closing (Jai Mata Di) | Devotional, uplifting | Full | Peak |

### General Rules

1. **Respectful above all:** The Divine Feminine is treated with utmost reverence. No casual or flippant tone.
2. **Storytelling with devotion:** Balance between engaging narrative and spiritual awe.
3. **Sanskrit terms:** Pronounce correctly, provide natural Hindi explanation after first use.
4. **Emotional range:** Can be dramatic (battle scenes), tender (Skandamata/Mother), powerful (Kalaratri), peaceful (Mahagauri).
5. **No slang:** Formal-to-semi-formal Hindi throughout.
6. **Consistency:** Same voice throughout all 75-90 scenes.

## Language Handling

### Hindi (Devanagari) Script

**Primary narration language:** Hindi (Devanagari)

### Sanskrit Term Protocol

| Term | First Mention | Subsequent Mentions |
|---|---|---|
| शक्ति (Shakti) | शक्ति (Shakti) — the Divine Feminine energy | शक्ति |
| देवी (Devi) | देवी (Devi) — the Goddess | देवी |
| महिषासुर (Mahishasura) | महिषासुर (Mahishasura) — the buffalo demon | महिषासुर |
| दुर्गा (Durga) | दुर्गा (Durga) — the invincible one | दुर्गा |
| देवीमाहात्म्य (Devi Mahatmya) | देवीमाहात्म्य (Devi Mahatmya) — the glory of the Goddess | देवीमाहात्म्य |
| विजयादशमी (Vijayadashami) | विजयादशमी (Vijayadashami) — the tenth day of victory | विजयादशमी |
| नवरात्रि (Navratri) | नवरात्रि (Navratri) — nine nights | नवरात्रि |
| नवदुर्गा (Navadurga) | नवदुर्गा (Navadurga) — nine forms of Durga | नवदुर्गा |

**Rule:** Sanskrit/Devanagari terms are always presented as: **Devanagari (Roman transliteration) — Hindi explanation**

### Language Mixing Rules

| Situation | Rule |
|---|---|
| First mention of a Sanskrit term | Devanagari + transliteration + Hindi explanation |
| Subsequent mentions of same term | Devanagari only (familiar to audience) |
| Mantras | Full Devanagari + transliteration + meaning |
| Place names | Standard Hindi pronunciation |
| Names of forms | Devanagari + transliteration at first mention |

### No Language Mixing Between Hindi and English in Narration
- All narration is in Hindi (Devanagari) only
- No English words mixed into Hindi narration
- English terms only in on-screen text subtitles (if added later)

## Citation Style in Script

| Type | Format | Example |
|---|---|---|
| Scriptural reference | "देवीमाहात्म्य में कहा गया है कि..." | "As stated in the Devi Mahatmya..." |
| Scholarly reference | "विद्वानों के अनुसार..." | "According to scholars..." |
| Historical reference | "इतिहास के अनुसार..." | "According to history..." |
| Direct quote from scripture | Devanagari quote + attribution | "अहं स्वयंभूः..." — Devi Mahatmya |

---

## Profanity Policy

**Zero tolerance.** No profanity, crude language, or disrespectful references. This is devotional content.

---

## How to Handle Numbers, Dates, Names

| Element | Rule |
|---|---|
| Numbers (Hindi) | Written in Devanagari numerals for narration (१, २, ३...) |
| Numbers (on-screen) | Devanagari numerals in graphics |
| Dates | Mentioned naturally in narration — "सातवीं सदी" (7th century) |
| Place names | Standard Hindi names (कोलकाता, गुजरात, मैसूर) |
| Person names | Standard Hindi pronunciation of Sanskrit names |
