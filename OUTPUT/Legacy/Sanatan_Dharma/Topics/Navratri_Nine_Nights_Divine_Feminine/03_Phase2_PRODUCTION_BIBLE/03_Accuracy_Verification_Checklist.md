# Accuracy Verification Checklist

## Project: Navratri — The Nine Nights of the Divine Feminine

---

## Category: Sanatan & Devotional

---

## Verification Rules

### Mythological Claims

| Rule ID | Rule | Requirement | Max Failures |
|---|---|---|---|
| AC-01 | All mythological narratives (Devi Mahatmya) must cite the specific chapter and verse reference | Source: Devi Mahatmya + academic commentary | 0 |
| AC-02 | Names of all 9 forms of Durga must be accurate and in correct sequence | Source: Devi Mahatmya, Kinsley | 0 |
| AC-03 | Mantras must be correctly transliterated and attributed | Source: Original texts (Devi Mahatmya, Kalika Purana) | 0 |
| AC-04 | Sanskrit terms must be properly explained when first introduced | Source: Standard Sanskrit dictionaries | 0 |
| AC-05 | Dates and time periods must be sourced from academic consensus | Source: Coburn, Kinsley, Pintchman | 0 |

### Historical Claims

| Rule ID | Rule | Requirement | Max Failures |
|---|---|---|---|
| AC-06 | Historical dates (e.g., first Durga Puja in 1790, Mysore Dasara since 1610) must be from primary historical records | Source: Colonial records, Mysore royal records | 0 |
| AC-07 | Archaeological claims must reference ASI or credible archaeological bodies | Source: ASI reports | 0 |
| AC-08 | When exact dates are uncertain, use ranges (e.g., "5th-7th century CE") not single dates | Source: Academic consensus | 0 |

### Philosophical Claims

| Rule ID | Rule | Requirement | Max Failures |
|---|---|---|---|
| AC-09 | Philosophical interpretations must distinguish between scriptural fact and interpretive commentary | Source: Primary texts for facts, academic sources for interpretation | 0 |
| AC-10 | Multiple philosophical traditions (Shakta, Shaiva, Vaishnava) must be represented if discussed | Source: Multiple Puranas, academic sources | 0 |

### Regional Claims

| Rule ID | Rule | Requirement | Max Failures |
|---|---|---|---|
| AC-11 | Regional variations must be presented as exactly practiced — no homogenization | Source: Regional cultural records, community documentation | 0 |
| AC-12 | Sensitive practices (e.g., animal sacrifice) must be presented fairly with historical and modern context | Source: Historical records, modern reports | 0 |

---

## Red Flags

| Red Flag | Action Required |
|---|---|
| Incorrect sequence of Navadurga | STOP — fix immediately, this is core content |
| Wrong Sanskrit transliteration | STOP — verify with authoritative source |
| Missing source for any factual claim | STOP — add source before proceeding |
| Dismissive tone toward any tradition | STOP — revise to respectful framing |
| Conflating different regional practices | STOP — clarify regional specificity |

---

## Minimum Source Counts

| Section | Minimum Sources Required |
|---|---|
| Mythology (Devi Mahatmya narrative) | 2 (primary text + academic commentary) |
| Navadurga descriptions | 2 (primary text + Kinsley) |
| Regional variations | 1 per region discussed |
| Historical development | 2 (academic + archaeological) |
| Philosophy | 2 (primary + academic) |
| Modern celebrations | 1 (community/record source) |

---

## Scriptural Accuracy Standards (Sanatan Category)

- All Devi Mahatmya references must match established translations
- Sanskrit terms: use Devanagari + transliteration + meaning
- Mantras: full form, transliteration, meaning
- No invented or misattributed quotes from scriptures
- Puranas correctly attributed (Markandeya, Kalika, Skanda, Devi Bhagavata)
- Vedic references (Devi Suktam, Sri Suktam) to correct suktas and mandalas
